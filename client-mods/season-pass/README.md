# Native Aetherfall Season Pass integration

See [SEASON_PASS.md](../../docs/SEASON_PASS.md) for gameplay, reward selection, configuration and deployment.

`prepare.py` stages an incremental patch from the supported English Aion 4.8 NA x64 client. `verify_package.py` reports `OK`/`FAIL` for archive/signature/hash and exact DLL bounds. `install.ps1` requires Aion to be closed and backs up every changed file; `restore.ps1` restores that snapshot while retaining server data. `verify_browser.py` checks the real Aion browser in a separate process against an isolated HTTP fixture, using the original native item icon bridge.

For players connecting from other PCs, build with the server's HTTPS origin: `python client-mods/season-pass/prepare.py --client "C:\Aion 4.8 NA" --output "C:\Aion-SeasonPass-Staged" --server-url "https://play.example.com"`. Loopback remains the default for same-PC use. Remote plain HTTP is rejected. The server must publish the Season Pass route through an HTTPS reverse proxy while keeping its marketplace listener private; see [remote-player setup](../../docs/SEASON_PASS.md#remote-players-and-the-in-game-browser). Do not distribute a prepared client snapshot: it contains original Aion files and is bound to one installed client. Share the source tools and have each player stage the patch from their own supported client.

The existing fullscreen Market dialog hosts the pass, including its stock native close control. The exact `/market/pass` route gets the character's native account token. Compact route comparison and suffix writes fit the existing 512-byte authentication cave; no new DLL or renderer hook is introduced. Preparing a package never writes to the installed client.

The browser UI uses readable 13–18px labels and explicit icon/name/status rows. Narrow windows scroll the reward track instead of shrinking text. Every item icon, including the detail dialog and native box contents, carries the same `nc://aion.ItemInfo/ItemTooltip` title/link as Central Market. Hover-event tests run through Aion's actual Awesomium engine; the installed browser receiver already uses mouse-positioned native tooltips. Purchase cards calculate item totals from the current reward state and distinguish included tracks, exact quantities, random/selection boxes, and the one-time level boost. The wording describes enchantment, tempering, socketing, pets, mounts and equipment remodeling directly. Media files are read on each HTTP request, so UI-only updates need no client replacement or GameServer restart. Reload the pass to receive the new version.

The season summary is centered horizontally and vertically inside its artwork. The software browser paints high-resolution transparent images slowly when they are repeatedly scaled. `OptimizeArtwork.java` builds smaller, alpha-preserving PNG render copies under `game-server/config/season-pass/media/optimized`, retaining the original illustrations beside that directory. Build them with `java client-mods/season-pass/OptimizeArtwork.java game-server/config/season-pass/media game-server/config/season-pass/media/optimized`. `install_ui.py` backs up and installs the three browser files plus those four render copies at the existing image routes. Its receipt records original artwork hashes and verifies that server binaries, rewards, missions and box data stay unchanged.

Only the selected page renders; an unchanged state refresh preserves its DOM, hover and scroll position. Mission reset labels update without rebuilding mission rows. Large blurred shadows are removed while retaining the frame art and track colors. `verify_browser.py --profile --baseline-only --viewport 1920x1052 --browser-bin <client-bin64> --report <output.json>` measures input-to-paint latency in the installed Aion browser, using an isolated account fixture. Measurements include browser IPC and software painting, and exclude the game's texture upload and frame time. Omit `--baseline-only` to run temporary diagnostic styles inside the isolated test. Functional checks additionally verify centered summary bounds, lazy pages, unchanged refreshes and changed mission progress.

The gold ticket HUD shortcut uses the existing `AionMarketShortcut.dll` dispatch and layout hooks. It sits directly above Central Market in both native HUD styles with a 2px gap, has normal/hover/pressed skins, an English tooltip and `/seasonpass` action. Its original generated PNG is `assets/ticket-outlined.png`; prompt and provenance are in `ARTWORK.md`. Both base and active English resources are patched, preserving all other skins, widgets, localization entries and texture/archive data. `verify_package.py` includes exhaustive resource comparisons; `client-mods/market-shortcut/verify_native.py` executes the real hooks and compiled callback at four UI scales. Installed client bundle: `output/season-pass/client-v4`; installed server bundle: `output/season-pass/server-v9.zip`. The latter records the already restored live box data as its original baseline and merges only pass classes/hooks onto the deployed JAR, preserving unrelated entries. `verify_installed.py` verifies installed files and the actual English hover tooltip **Aetherfall Season Pass** in both HUDs.
